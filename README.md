# 📌 О проекте

В рамках проекта проведён аналитический разбор пользовательской активности сервиса **Яндекс.Афиша** на основе исторических данных о заказах.

Цель исследования — выявить поведенческие закономерности пользователей, определить факторы повторных покупок и подготовить бизнес-рекомендации для роста удержания клиентов.

---

# 🎯 Бизнес-задачи

- определить факторы повторных заказов;
- выявить ранние признаки оттока пользователей;
- найти поведенческие особенности лояльных клиентов;
- исследовать частоту покупок;
- определить направления роста retention;
- подготовить рекомендации для маркетинга и продукта.

---

# 📊 Feature Engineering

Для каждого пользователя сформирован профиль поведения:

- количество заказов;
- средний интервал между заказами;
- средний чек;
- среднее число билетов в заказе;
- регион первой покупки;
- устройство первого заказа;
- предпочитаемая категория событий.

# 📈 Проведённый анализ

## 1. Исследовательский анализ данных (EDA)

- распределение заказов;
- анализ выручки;
- частота покупок;
- повторные покупки;
- пользовательская активность.

## 2. Сегментация пользователей

Выделены группы пользователей по интенсивности покупок и вовлечённости.

## 3. Корреляционный анализ факторов повторных заказов

Наиболее значимые признаки:

| Показатель | Корреляция |
|-----------|-----------|
| Средний интервал между заказами | 0.42 |
| Среднее число билетов | 0.30 |
| Средний чек | 0.26 |

---

# 🔍 Основные выводы

## Повторный возврат критически важен

Чем быстрее пользователь возвращается после предыдущей покупки, тем выше вероятность новых заказов.

## Размер заказа связан с лояльностью

Пользователи, покупающие несколько билетов, проявляют более высокую активность.

## Высокий средний чек — хороший сигнал

Пользователи с большим средним чеком чаще совершают повторные покупки.

# 💡 Бизнес-рекомендации

## Рост retention

- запуск CRM-коммуникаций после первой покупки;
- стимулирование второй покупки в короткий срок;
- персональные предложения новым пользователям.

## Рост выручки

- пакетные предложения на несколько билетов;
- рекомендации премиальных событий;
- cross-sell смежных мероприятий.

## Снижение оттока

- отслеживание роста интервала между заказами;
- модель прогнозирования churn-risk;
- реактивационные кампании.
